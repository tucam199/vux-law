# **App Name**: VUX Fine Central

## Core Features:

- Regulation Creation: Create penalty regulations: Define fault categories, detailed violations, and penalty options (fine, restriction).
- Penalty Configuration: Configure penalty type: Input amount for fines (X.XXX đ format), or restriction details as text.
- Save and edit fines: Implement rule management features, allowing users to save newly created regulations, and modify the values in regulations later on.

## Style Guidelines:

- Dark mode primary color: Soft, desaturated blue (#527BAB) for a professional and calming feel.
- Dark mode background color: Dark gray (#222222) for a modern and sleek look.
- Accent color: A vibrant, lighter blue (#6FB5F2) to highlight key interactive elements.
- Font: 'Inter' (sans-serif) for body text and headlines.
- Simple, outline-style icons to represent different penalty categories.
- Consistent padding and spacing throughout the UI, using a grid system for alignment.
